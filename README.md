# 통통 가이드

국립한국교통대학교 충주캠퍼스 학생이 만든 **비공식** 생활 안내 웹앱입니다.

바로 열기: https://jyynet03.github.io/knut-pass/

- 오늘 내 수업(출발 안내판), 할 일·달력, D-day, 일 년 목표와 경력 표시
- 캠퍼스 + 대학가 지도: 밥집·카페·편의점·학생식당·버스 정류장·충북선, 영업 상태
- 건물 번호와 학과, 생활관, 교통, 학사 흐름, 교통대 공식 링크 모음
- 학생 게시판 (Firebase, 설정 방법은 [FIREBASE_SETUP.md](FIREBASE_SETUP.md))

할 일, 시간표, 목표 같은 개인 기록은 각자 폰 브라우저에만 저장됩니다.

화면별 바로가기: `#eat` 밥집 지도 · `#board` 게시판 · `#todo` 할 일·달력 · `#goal` 목표 · `#links` 링크 모음 · `#bldg` 건물 · `#transit` 교통 · `#acad` 학사 · `#E14` 처럼 건물 번호

학교 공식 서비스가 아닙니다. 영업시간·학과 배치 등은 바뀔 수 있으니 공식 정보는 [www.ut.ac.kr](https://www.ut.ac.kr)에서 확인하세요.
